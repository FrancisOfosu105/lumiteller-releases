# LumiTeller

A Mac app for making animated picture-book stories.

## Download

**[Download the latest version](https://github.com/FrancisOfosu105/lumiteller-releases/releases/latest)** — click `LumiTeller.dmg` under *Assets*.

Needs macOS 15 (Sequoia) or later. Works on Apple Silicon and Intel Macs.

## Install

1. Open `LumiTeller.dmg` and drag **LumiTeller** into the **Applications** folder.
2. Open LumiTeller from Applications. The first time, macOS says it "can't be checked for malicious software" — click **Done**.
3. Open **System Settings → Privacy & Security**, scroll down, and click **Open Anyway** next to LumiTeller. Enter your Mac password.
4. LumiTeller opens. From now on it opens like any other app.

This is a test version, so macOS asks once before opening it.
